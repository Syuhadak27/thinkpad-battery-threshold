ThinkPad Battery Threshold

Tool sederhana untuk mengatur batas pengisian baterai Lenovo ThinkPad agar kesehatan baterai lebih terjaga.

Cara Menggunakan

1. Ekstrak file ZIP ke folder mana saja.
2. Instal driver yang tersedia di folder "driver" (cukup satu kali).
3. Jalankan "start.bat".
4. Pilih pengaturan sesuai kebutuhan.

Pilihan Pengaturan

Menu| Berhenti Mengisi| Mulai Mengisi
Seimbang| 75%| 65%
Standar| 85%| 75%
Maksimal| 95%| 85%

Tersedia juga menu untuk memeriksa status baterai dan menonaktifkan batas pengisian.

Penjelasan

- Ambang berhenti: Persentase ketika pengisian baterai dihentikan.
- Ambang mulai: Persentase ketika pengisian baterai dimulai kembali setelah kapasitas turun.

Contoh: pengaturan 85% / 75% berarti pengisian berhenti pada 85% dan dimulai kembali ketika baterai turun hingga ambang 75%.

Kompatibilitas

Model ThinkPad yang telah diuji:

- X230
- T530
- T570
- X280
- X260

Kompatibilitas model lainnya bergantung pada dukungan perangkat keras, firmware, dan driver.
